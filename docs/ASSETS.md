Complete generation prompts, processed-file SHA-256 hashes and supplied screenshot filenames are recorded in `asset-provenance.json`. Original raster sources remain available; final production WebP/JPG assets are in `public/art`. Generated artworks are concepts rather than reported completed client case studies.

Font software is supplied through Fontsource; its OFL text is copied into `docs/licenses`. The lettering script reproduces the required outline subsets from the installed WOFF sources with FontTools; no Python generation step is needed for a normal website build.

No paid 3D provider was called and no provider rig/Blender receipt is claimed. The Three.js male is authored articulated geometry, not a photographed/scanned likeness. Native game-dev and Blender are unavailable. No video, soundtrack or external credential is required to run the default portfolio.
